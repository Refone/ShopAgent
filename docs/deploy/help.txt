NAME
       deploy.py - ShopAgent 的构建、部署与运维脚本

SYNOPSIS
       python deploy.py
       python deploy.py COMMAND [SERVICE ...] [OPTIONS]
       python deploy.py help

DESCRIPTION
       deploy.py 负责 ShopAgent 本地环境的构建、启动、状态检查、数据库重置和卸载。

       不带参数运行时进入 ASCII 交互式控制台。控制台启动时会自动执行依赖检查、
       配置检查、端口检查和服务状态检查，并把结果显示在 ASCII 面板中。

COMMANDS
       env [-f|--force]
              从 .env.example 创建 .env；--force 会覆盖已有文件。

       build [SERVICE ...]
              构建服务。SERVICE 省略时等于 all。
              可用值：all、ecommerce、customer、ai、frontend。

       deploy [SERVICE ...] [--skip-build]
              先构建再部署服务；--skip-build 复用已有构建产物。

       status [--strict]
              在命令行输出服务状态。--strict 时只要有服务未运行就返回非零退出码。

       undeploy [--volumes] [--yes]
              停止本地进程和 ecommerce 容器。默认保留 PostgreSQL/Redis 数据卷；
              --volumes 会删除数据卷，--yes 跳过确认。

       reset-db [--yes]
              删除 PostgreSQL 数据卷和 Redis 数据，重建三个数据库并写入演示数据；
              如果重置前 ecommerce/customer 正在运行，会自动恢复。

       help
              输出本手册。交互控制台内按 ? 也可以查看同一份手册。

SERVICES
       all            ecommerce、customer、ai、frontend 四个组件
       ecommerce      Docker Compose 管理的电商中台（含 PostgreSQL/Redis）
       customer       uv/uvicorn 启动的 customer-service
       ai             当前尚未实现，构建和部署会自动跳过
       frontend       user-frontend 和 admin-frontend

INTERACTIVE
       交互控制台启动时的检查项：
         - 依赖：docker compose、Docker daemon、uv、node、npm
         - 配置：.env 是否存在且通过校验
         - 端口：服务端口、PostgreSQL、Redis 的监听状态
         - 服务：HTTP 健康检查、PID、容器数量

       方向键上下移动选择，左右跳到服务区或操作区。底部快捷键会随当前选择变化。
       执行构建、部署、停止或重置时会临时退出控制台显示完整命令输出，结束后按
       Enter 返回并自动刷新检查结果。

KEYS
       Up / Down       选择上一个或下一个服务/操作
       Left / Right    跳到服务区或全局操作区
       Enter           启动/重启选中的服务，或执行选中的全局操作
       B               重建选中的服务
       R               重启选中的服务
       S               停止选中的服务
       L               查看选中服务的日志
       A               部署全部服务（构建 + 启动）
       D               重置全部数据库（需要确认）
       F               重新执行依赖、配置、端口和服务检查
       J / K           向下/向上翻页
       Home / End      跳到内容顶部/底部
       ? 或 H          打开本手册
       Q / Esc         退出控制台

ENVIRONMENT
       .env            统一配置。前端 HOST/PORT 同时用于派生后端 CORS 白名单。
       JWT_SECRET      customer-service 与 ecommerce-service 共用的 JWT 密钥
       POSTGRES_*      PostgreSQL 连接与宿主机映射端口
       *_SERVICE_*     各服务的监听地址和端口
       USER_FRONTEND_* / ADMIN_FRONTEND_*   前端监听地址和端口
       REDIS_PORT      Redis 宿主机映射端口

FILES
       .env                        本地配置，不纳入版本控制
       docs/deploy/help.txt        本手册
       var/run/*.pid               控制台启动的后台进程 PID
       var/logs/deploy/*.log       控制台启动的进程日志
       var/logs/customer-service/  customer-service 自身按天切分的日志

EXAMPLES
       python deploy.py
              打开交互式控制台。

       python deploy.py deploy
              构建并启动全部服务。

       python deploy.py build customer
              只构建 customer-service。

       python deploy.py status --strict
              命令行检查状态，CI 中可直接判断退出码。

       python deploy.py reset-db --yes
              CI 中无确认地重置全部数据库。

EXIT STATUS
       0       成功
       1       执行失败或 --strict 状态检查未通过
       2       参数错误，或交互模式没有 TTY
       130     用户中断
